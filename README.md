# **DonTour — AI Route Builder**

**Bilingual README (English + Russian)**

---

## **Overview / Обзор**

### English

**DonTour** is an AI-powered travel assistant that generates personalized travel routes.
The system analyzes locations, attractions, hotels, parks, cafés, and transportation options to provide optimized itineraries and recommendations on where to stay and what to visit.

### Русский

**DonTour** — это ИИ-помощник для путешествий, создающий персональные маршруты.
Система анализирует локации, достопримечательности, отели, парки, кафе и варианты транспорта, предлагая оптимальные маршруты и рекомендации о том, где остановиться и что посмотреть.

## **How It Works / Как работает**

### English

DonTour processes:

* user preferences
* geographic and POI data
* transport availability
* distances and optimal transitions
* accommodation options

The AI then constructs a route that maximizes efficiency and relevance.

### Русский

DonTour анализирует:

* предпочтения пользователя
* геоданные и точки интереса
* транспортную доступность
* расстояния и оптимальные переходы
* варианты размещения

После этого ИИ формирует наиболее эффективный и подходящий маршрут.
